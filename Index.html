파일명 일괄 변경기

폴더 안의 여러 파일명을 한 번에 정리합니다. 특정 문자 삭제, 접두어·접미어 추가, 찾아바꾸기, 특정 단어 앞뒤에 문자 끼워넣기를 조합해서 규칙을 만들면 실시간으로 미리보기가 갱신됩니다.

1. 폴더 선택

폴더를 선택하면 안의 파일 목록을 불러옵니다. 하위 폴더는 포함하지 않습니다.

선택된 폴더 없음

2. 변경 규칙

아래 항목은 조합해서 함께 적용할 수 있습니다. 확장자(.xlsx 등)는 규칙과 무관하게 항상 보존됩니다.

적용 순서: 문자 제거 → 찾아바꾸기 → 단어 앞뒤 끼워넣기 → 접두어/접미어

3. 미리보기

0개
폴더를 선택하면 여기에 변경 전/후 이름이 표시됩니다.

4. 파일명 모아서 엑셀로 저장

규칙 적용과 상관없이, 현재 불러온 파일들의 이름만 따로 정리해 엑셀 목록으로 저장합니다.

5. 적용

Chrome·Edge(데스크톱)에서 폴더를 선택했다면 브라우저 안에서 바로 이름을 바꿀 수 있습니다. 그 외 환경에서는 배치파일을 받아 폴더 안에서 실행하세요.

배치파일은 다운로드 후 파일이 들어있는 폴더 안으로 옮긴 뒤 더블클릭해서 실행합니다. "지금 바로 이름 변경"은 실행을 되돌릴 수 없으니 실행 전 미리보기를 꼭 확인하세요.
